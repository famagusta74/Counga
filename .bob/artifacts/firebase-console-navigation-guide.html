🗄 Part 2 — Enable Firestore Database
1

In the same left sidebar under Build, click Firestore Database

⚠️ This is Firestore, NOT "Realtime Database". Counga uses Firestore. Your football game uses Realtime Database — they are separate and won't interfere.
2

Click Create database

A dialog appears. Choose Start in production mode and click Next

3

Choose the location. Select europe-west1 (Belgium) — same region as your existing Realtime Database.

Click Enable

Wait ~30 seconds for it to provision.

✅ Firestore is now active.
4

Click the Rules tab at the top of the Firestore page.

Delete everything in the editor and paste this:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid} { allow read, write: if request.auth != null && request.auth.uid == uid; } match /games/{gameId} { allow read: if request.auth != null; allow create: if request.auth != null; allow update: if request.auth != null; match /rounds/{roundId} { allow read, create: if request.auth != null; } } } }

Click Publish

✅ Security rules are now live.
🎉 All done! Your Counga app is now fully connected to Firebase.
