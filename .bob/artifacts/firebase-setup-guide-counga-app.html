🔥 Firebase Setup Guide

Activate Firebase for the Counga score keeper app · Uses your existing football-prediction-game-ca155 project

✓

Step 1 — Firebase project already exists

You already have the football-prediction-game-ca155 Firebase project. No need to create a new one.

✅ Project ID: football-prediction-game-ca155 — ready to use.
2

Step 2 — Enable Google Authentication

Open the Firebase Console and navigate to your project:

https://console.firebase.google.com/project/football-prediction-game-ca155/authentication
  • Click Get started if Authentication isn't enabled yet
  • Go to the Sign-in method tab
  • Click Google → toggle Enable ON
  • Set a support email (your Gmail address)
  • Click Save
⚠️ Also enable Anonymous sign-in (for guest players):
Sign-in method → Anonymous → Enable → Save
3

Step 3 — Add Authorized Domain

Still in Authentication, click the Settings tab:

https://console.firebase.google.com/project/football-prediction-game-ca155/authentication/settings
  • Scroll to Authorized domains
  • Click Add domain
  • Enter: famagusta74.github.io
  • Click Add
✅ This allows the Google sign-in popup to work from your GitHub Pages URL.
4

Step 4 — Enable Firestore Database

https://console.firebase.google.com/project/football-prediction-game-ca155/firestore
  • Click Create database
  • Choose Start in production mode
  • Select region: europe-west1 (matches your existing Realtime DB)
  • Click Enable
⚠️ Counga uses Firestore (not Realtime Database). Your football game data stays separate — Counga data goes under its own games/ collection.
5

Step 5 — Deploy Firestore Security Rules

In Firestore → Rules tab, paste these rules and click Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /games/{gameId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow update: if request.auth != null;
      match /rounds/{roundId} {
        allow read, create: if request.auth != null;
      }
    }
  }
}

7

Step 7 — Enable GitHub Pages

https://github.com/famagusta74/Counga/settings/pages
  • Under Source, select Deploy from a branch
  • Branch: gh-pages  /  folder: / (root)
  • Click Save
⚠️ The gh-pages branch is created automatically by GitHub Actions on the first successful build. If it doesn't appear yet, run the workflow first (Step 8).
8

Step 8 — Trigger the Deployment

https://github.com/famagusta74/Counga/actions
  • Click Deploy to GitHub Pages workflow
  • Click Run workflow → Run workflow
  • Wait ~2 minutes for the build to complete ✅
🚀 Once green, your app is live at:
https://famagusta74.github.io/Counga/
9

Step 9 — Test on your phone

  • Open https://famagusta74.github.io/Counga/ on your phone
  • Sign in with Google or play as a guest
  • On iOS: tap Share → Add to Home Screen to install as an app
  • On Android: tap the browser menu → Install app
✅ The app works offline after first load thanks to the PWA service worker.
